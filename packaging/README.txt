AlenPlayer {VERSION}
====================

Lightweight portable media player for Windows - video, music and photos.
https://github.com/a1enq/AlenPlayer

HOW TO USE
  1. Keep AlenPlayer.exe and libmpv-2.dll in the same folder.
  2. Run AlenPlayer.exe. No installation needed.
  3. To open files with a double-click: menu "..." -> "Set as default player".

REQUIREMENTS
  Windows 10 (1903 or newer) or Windows 11, 64-bit.

FILES
  AlenPlayer.exe            the player
  libmpv-2.dll              playback engine (mpv / FFmpeg)
  LICENSE.txt               GNU General Public License v3.0
  THIRD-PARTY-NOTICES.txt   licenses and source code of bundled components

Source code: https://github.com/a1enq/AlenPlayer
